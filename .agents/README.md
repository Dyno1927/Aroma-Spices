# Shared agent workspace

- `AGENTS.md` contains shared project memory and working agreements.
- `AGY/` contains AGY-specific material and is owned by AGY.
- `rules/` contains agent-specific rules already present in this project.
- `skills/` is reserved for portable `SKILL.md` workflows shared by compatible agents.
- `hooks/` and MCP configuration are created only when a supported plugin or tool integration requires them.
